# Palette's UX & Accessibility Journal

## 2025-02-14 - Interactive Tactile Feedback with Transition Timing
**Learning:** Adding active tactile state transitions (like `active:scale-95`) on small interactive elements such as Back buttons can feel abrupt or jarring unless paired with standard, smooth Tailwind `transition` class.
**Action:** Always combine interactive scaling classes (e.g. `active:scale-95`) with standard transition classes (e.g. `transition`) for a professional, physics-aligned feel.
