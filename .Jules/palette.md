## 2025-05-18 - Position Workspace Tab Navigation & Header Back Button ARIA Pattern
**Learning:** PositionPilot uses a Stitch dark theme (`bg-stitch-bg`) with customized tabs in workspace headers (`HoldingDetail`). Custom `<button>` tab items require explicit `role="tablist"` + `aria-label`, `role="tab"`, `aria-selected`, and `focus-visible:ring-2 focus-visible:ring-stitch-accent/50 focus-visible:ring-offset-2 focus-visible:ring-offset-stitch-bg` offset rings for high-contrast accessibility.
**Action:** When implementing or updating page headers or tab navigation bars in Stitch-themed pages, ensure tab containers use `role="tablist"`, tab buttons have `role="tab"` and `aria-selected`, and back navigation buttons have explicit `aria-label` with `active:scale-95` tactile scaling.
