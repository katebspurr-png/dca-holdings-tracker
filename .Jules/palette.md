## 2025-05-14 - Button Tactile Feedback
**Learning:** Adding 'active:scale-95' and using 'transition' (instead of property-specific transitions like 'transition-colors') provides immediate and synchronized tactile feedback for button presses, enhancing the perceived responsiveness of the UI.
**Action:** Use 'active:scale-95' and 'transition' for primary interactive elements to ensure consistent tactile feedback.
