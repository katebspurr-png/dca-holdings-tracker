## 2026-03-09 - Reusable Tactile Keyboard Focus Pattern for Stitch Design System
**Learning:** For bottom tab bars and floating action elements, default focus states are visually jarring or invisible in dark/glow theme overlays. Applying a custom `focus-visible:ring-2 focus-visible:ring-stitch-accent/50 focus-visible:ring-offset-2 focus-visible:ring-offset-stitch-bg focus:outline-none rounded-xl` creates a highly-accessible, gorgeous, glowing outline. Adding `active:scale-95 transition-all duration-150` on the same button balances visual keyboard clarity with direct tactile touch feedback without screen layout shifts.
**Action:** Always pair custom offset focus rings with `active:scale-95` tactile scaling on global/persistent controls to ensure consistent keyboard-and-touch-safe accessibility.
