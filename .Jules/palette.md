## 2025-07-19 - Bottom Navigation Accessibility & Tactile Feedback Patterns
**Learning:** Mobile-first dashboard applications that use standard fixed bottom tab navigation often suffer from focus invisibility and lack screen-reader context because buttons rely on visual highlights (such as custom active accent bars) without backing them up with aria-current. Standardizing on `aria-current={active ? "page" : undefined}` and explicit themed focus-visible rings is a critical reusable accessibility design pattern. Additionally, combining active presses with general transition properties instead of restrictive `transition-colors` guarantees exceptionally smooth micro-UX tactile scaling.
**Action:** When adding tactile or focus indicators on interactive custom buttons or links in this application, ensure focus-visible styles match the standard `focus-visible:ring-2 focus-visible:ring-stitch-accent/50 focus-visible:ring-offset-2 focus-visible:ring-offset-stitch-bg focus:outline-none` palette pattern, support active scale downs using `active:scale-95 transition duration-150`, and declare proper `aria-current` indicators.
