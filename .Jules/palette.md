## 2025-09-14 - Radix UI SelectTrigger Accessible Labels & Dialog Form State Feedback
**Learning:** Radix UI `SelectTrigger` components inside modal forms do not automatically bind to standard HTML `<label>` elements unless explicitly associated via `id`/`htmlFor` and explicit `aria-label` attributes. Furthermore, form submission buttons inside modal dialogs require visual loading states (`Loader2` spinner + disabled state + dynamic text + explicit `aria-label`) to inform both visual and screen reader users of pending async network/storage requests.
**Action:** Always provide explicit `aria-label` and `id`/`htmlFor` bindings on Radix `SelectTrigger` elements, and include visual spinner feedback paired with tactile feedback (`active:scale-95 transition-all duration-150`) on modal submit buttons.
