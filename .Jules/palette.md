## 2026-03-31 - Destructive Action Confirmation Pattern in Mobile-First Financial Planning UI
**Learning:** Destructive actions with irreversible consequences (such as resetting locally stored portfolio data or clearing demo sandboxes) placed in secondary tabs like Settings can easily be tapped accidentally on touch devices if no modal confirmation step exists. Using Radix UI `AlertDialog` ensures modal focus trapping, clear explanation of consequences differentiated by demo vs. real environment, and standard cancellation safety for touch and keyboard users alike.
**Action:** Always intercept destructive data deletion actions with an accessible `AlertDialog` containing explicit contextual descriptions and styled with `focus-visible` offset rings and tactile active press transitions.
