## 2025-05-14 - Tactile Feedback and Accessibility in Navigation Tabs
**Learning:** Adding `active:scale-95` to navigation buttons provides immediate tactile feedback that makes the app feel more native and responsive. Combining this with `aria-current="page"` ensures the UI is both physically satisfying and semantically correct for screen readers.
**Action:** Consistently apply `active:scale-95` and `aria-current` to all main navigation elements and custom buttons to maintain a high-quality, accessible user experience.
