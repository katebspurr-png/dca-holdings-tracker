## 2025-05-14 - Bottom Navigation Tactile Feedback & Accessibility
**Learning:** Adding 'active:scale-95' to custom interactive elements (not using the global Button component) provides immediate tactile feedback, making the app feel more responsive and high-quality, especially on mobile. Using 'aria-current="page"' ensures screen reader users can identify the active navigation state.
**Action:** Always check custom navigation components for tactile feedback and proper ARIA state attributes.
