## 2026-10-15 - Micro-UX and Accessibility Enhancements for HoldingFormDialog
**Learning:** Adding explicit ARIA labels on select trigger elements and hiding decorative unit adornments (`$` and `%`) ensures screen readers do not read redundant clutter while maintaining visual clarity. Adding focus-visible offset ring styling and loading states improves tactile feedback for keyboard and assistive tool users.
**Action:** Always include focus-visible offset rings, state loading indicators, and explicit select trigger labels when working with dialog form controls.
