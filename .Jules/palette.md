## 2025-06-27 - Accessible Close Triggers in Radix Tabs List
**Learning:** Placing interactive controls (such as a scenario close trigger) inside semantic Radix `TabsTrigger` buttons can easily compromise keyboard accessibility and screen reader output if built using non-semantic elements like `<span>` with `role="button"` and missing keydown / tabindex attributes. However, using HTML nested `<button>` inside `<button>` triggers a React/DOM hydration nesting warning because inline elements cannot contain nesting buttons. The optimal solution is utilizing `<span>` with explicit `role="button"`, `tabIndex={0}`, standard focus indicators (`focus-visible:ring-offset-stitch-bg`), custom `e.stopPropagation()` and precise keyboard `onKeyDown` handlers. This preserves perfect visual/interactive excellence without violating HTML standards.
**Action:** Always replace nested click-handlers or non-semantic role="button" elements inside buttons with semantic-compatible `<span>` tags configured with `role="button"`, `tabIndex={0}`, custom keyboard event handling, localized `aria-label`s, and stop propagation.
