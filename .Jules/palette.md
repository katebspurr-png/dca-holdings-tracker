## 2025-05-20 - Semantic Buttons for State Toggles
**Learning:** While `Label` components are standard for form fields, interactive text elements that toggle application state (like theme names) are more accessible and intuitive when implemented as semantic `button` elements. This provides built-in keyboard navigation and clear focus indicators that a plain `span` or even a linked `label` might lack in complex layouts.
**Action:** Use `button` elements for interactive state-toggling text to ensure a predictable and accessible user experience.
