## 2026-05-20 - Tactile Feedback for Core Navigation
**Learning:** Interactive elements like navigation buttons feel significantly more responsive and "premium" when they provide immediate tactile feedback. Using `active:scale-95` is a simple but effective way to achieve this.
**Action:** Apply `active:scale-95` to custom buttons that don't use the standard UI library components, and ensure the `transition` class is used for smooth animations.
