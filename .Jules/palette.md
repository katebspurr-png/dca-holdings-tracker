## 2026-06-04 - Tactile feedback for interactive elements
**Learning:** Adding 'active:scale' (e.g., active:scale-95) along with a 'transition' class provides immediate tactile feedback, making the interface feel more responsive and high-quality, especially on touch-based devices.
**Action:** Use 'active:scale-95' for smaller buttons and 'active:scale-[0.98]' for larger card components to maintain a professional feel while providing clear interaction feedback.
