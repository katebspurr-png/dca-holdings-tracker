## 2025-05-15 - Tactile Navigation Feedback
**Learning:** Adding 'active:scale-95' to interactive elements provides immediate tactile feedback, making the app feel more responsive and high-quality, especially on mobile devices where tap targets need clear visual state changes.
**Action:** Apply 'active:scale-95' and the 'transition' shorthand to high-traffic navigation elements and buttons. Use the general 'transition' class (rather than property-specific ones like 'transition-colors' or 'transition-transform') when combining scaling with other transitions like color changes.
