## 2026-07-26 - [Workspace Tabs Accessibility & Tactile Micro-UX]
**Learning:** Custom tab navigation components (rendered using simple HTML `button` elements) often lack semantic elements, roles, and states for screen readers and keyboard users (e.g. `role="tablist"`, `role="tab"`, `aria-selected`). By implementing these standard ARIA roles along with modern tactile micro-interactions (`transition active:scale-95`) and explicit focus indicators (`focus-visible:ring-2`), the tabs become fully accessible, keyboard-navigable, and highly interactive.
**Action:** Always wrap custom button-based tab bars in a `role="tablist"` element, annotate tabs with `role="tab"` and `aria-selected={active}`, and style them with `transition active:scale-95` + `focus-visible:ring-2` styling.
