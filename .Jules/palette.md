## 2026-05-16 - Tactile Button Feedback and Form Ergonomics
**Learning:** Adding 'active:scale-95' to global button styles provides immediate, high-quality tactile feedback that makes the app feel more responsive. Using 'transition' (instead of 'transition-colors') ensures all properties (including scale and colors) animate in sync.
**Action:** Always consider tactile feedback for interactive elements and ensure 'autoFocus' is used on the primary input of any new modal forms to reduce user friction.
