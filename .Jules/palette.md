## 2026-03-26 - Accessible Segmented Button Radiogroup Custom Focus Rings
**Learning:** Custom styled buttons acting as segmented controls (like the default exchange selector) must be explicitly grouped inside `role="radiogroup"` with `role="radio"` and `aria-checked` attributes to align with accessibility expectations. Furthermore, adding `active:scale-95 transition` transitions ensures tactile feedback for mouse/touch interactions, while `focus-visible:ring-2 focus-visible:ring-stitch-accent/50 focus-visible:ring-offset-2 focus-visible:ring-offset-stitch-bg focus:outline-none` matches the app's dark-mode theme offset design system pattern beautifully for keyboard users.
**Action:** Always group custom button-based radio selectors in a container with role="radiogroup", and style individuals with role="radio", aria-checked, active scaling, and standard dark offset ring outlines.
