## 2025-05-15 - Improving Interaction Polish & Accessibility
**Learning:** Adding micro-interactions like `active:scale-95` provides immediate tactile feedback that makes the app feel more responsive and native. Combining this with accessibility features like `aria-current` and proper `focus-visible` states ensures the app is both delightful and inclusive.
**Action:** Always consider the "pressed" state of buttons and the focus state for keyboard users when touching any interactive component. Also, use `autoFocus` on the primary field of modal forms to reduce user friction.
