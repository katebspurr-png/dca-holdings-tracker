## 2025-02-17 - Theme Selection Segmented Control UX
**Learning:** Standard switch toggles for themes can be visually and cognitively ambiguous for users because it's not always clear which toggle state maps to which theme (is "on" light or dark?). Converting these toggles into semantic, button-based Segmented Controls (`role="radiogroup"` + `role="radio"`) with tactile scaling transitions (`active:scale-95`) provides an immediate, visual, accessible, and delighting upgrade that is completely screen-reader friendly and keyboard navigable.
**Action:** For non-binary options or preferences that represent explicit choices (like Light vs Dark theme), always prefer Segmented Controls over simple switches. Group them under a container with `role="radiogroup"`, link them to a group label, and style each option with `role="radio"`, `aria-checked`, and micro-interaction tactile animations.
