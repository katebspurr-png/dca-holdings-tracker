## 2025-05-15 - Tactile Feedback and Active State Accessibility
**Learning:** Adding `active:scale-95` to interactive elements like navigation tabs provides immediate tactile feedback, making the app feel more responsive and high-quality. Additionally, using `aria-current="page"` on active navigation links is essential for screen reader users to understand their current location within the application.
**Action:** Always apply `active:scale-95` with the `transition` utility to custom interactive elements and ensure `aria-current` is used for active navigation states.
