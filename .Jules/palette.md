## 2025-05-15 - Tactile Feedback in Mobile Navigation
**Learning:** Adding subtle tactile feedback (`active:scale-95`) to navigation elements on mobile-first applications significantly improves perceived responsiveness and user confidence. It provides immediate visual confirmation of a touch event before the navigation transition occurs.
**Action:** Always include `active:scale-95` (or similar proportional scaling) and a generic `transition` utility on high-frequency interaction elements like bottom tab bars.
