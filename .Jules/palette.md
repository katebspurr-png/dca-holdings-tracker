## 2025-09-18 - NotFound Page UX & Accessibility
**Learning:** Foundational error fallback views like 404 pages benefit significantly from semantic landmark tags (`<main>`), explicit `aria-label` attributes on navigation actions, and consistent design system focus ring / tactile active press feedback.
**Action:** Always wrap full-page fallback/error layouts in `<main>` landmarks and ensure link/button actions adhere to design system focus-visible offset ring styles and tactile active press scaling.
