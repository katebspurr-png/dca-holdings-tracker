## 2025-05-15 - [Consistent Focus Indicators]
**Learning:** In highly customized dark-themed dashboards (like "Stitch"), standard browser focus outlines are often invisible or clash with the design. Explicitly defined `focus-visible` states using the theme's accent color provide both accessibility and a "premium" interactive feel.
**Action:** Always ensure interactive elements (cards, custom buttons, menu triggers) have `focus-visible:ring-2` using the design system's primary accent color.
