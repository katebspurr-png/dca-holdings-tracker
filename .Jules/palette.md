## 2025-05-18 - Fallback Navigation on Not Found Detail Pages
**Learning:** When detail views (e.g. scenario or holding details) fail to load due to missing or invalid IDs, empty fallback text leaves users stranded; providing an accessible CTA button enables clear recovery navigation.
**Action:** Always include an accessible return action button with focus-visible offset ring styles, active tactile press feedback, and clear aria-labels on error/fallback detail views.
