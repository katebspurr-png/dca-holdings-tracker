## 2025-08-14 - [Back to Portfolio Navigation]
**Learning:** For page navigations that look and act like primary anchor links but are wrapped in interactive shadcn/Radix components (e.g., `<Button asChild>`), assigning tactile scaling `active:scale-95` paired with custom offset focused ring states improves directionality, visual delight, and keyboard-tabbing prominence. Explicit `aria-label` tags must target the semantic `<a>` link container created when `asChild` compiles into an anchor tag to prevent strictness locator violations in verification tools.
**Action:** Always add `active:scale-95 transition-all duration-150` and themed offset focus ring overrides when styling navigation links wrapped inside layout components, and assert their locator properties by targeting the compiled `link` role rather than the source wrapper.
