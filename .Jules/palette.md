## 2025-05-15 - Subtle Tactile Feedback and Semantic Navigation
**Learning:** Adding `active:scale-95` to navigation elements like `BottomTabBar` significantly improves the perceived responsiveness of mobile-first applications. Complementing this with `aria-current="page"` ensures the interface is both delightful for sighted users and semantically clear for screen reader users.
**Action:** Always include tactile feedback transitions and semantic state indicators in primary navigation components.
