# Palette's Journal

## 2025-06-08 - Tactile Feedback Pattern
**Learning:** Adding `active:scale-95` and the `transition` class to custom interactive elements (like navigation tabs or floating action buttons) provides immediate, high-quality tactile feedback that significantly improves the "feel" of responsiveness, especially on touch devices. This is often more effective than hover states or simple color shifts in a mobile-first context.
**Action:** Always apply `active:scale-95` and the general `transition` utility to interactive components that don't already benefit from a global design system button style.
