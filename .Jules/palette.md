## 2025-05-15 - Tactile Feedback and Contextual Focus
**Learning:** In a mobile-first local portfolio manager like PositionPilot, interactive elements benefit significantly from haptic-like visual feedback. Additionally, streamline form entry by immediately focusing the primary input field.
**Action:** Apply 'active:scale-95' and 'transition-all' to key interactive elements (buttons, navigation) and use 'autoFocus' on the most likely next input field (e.g., Ticker in HoldingFormDialog) to reduce friction.
