## 2025-05-15 - Interactive Navigation Tactile Feedback
**Learning:** Adding `active:scale-95` to navigation elements provides immediate tactile visual feedback that improves the perceived responsiveness of tap interactions in mobile-first applications.
**Action:** Use `active:scale-95` and the `transition` shorthand on primary navigation buttons to ensure synchronized animation with color changes.

## 2025-05-15 - ARIA Current for Navigation
**Learning:** Using `aria-current="page"` on active navigation links is essential for screen readers to convey the user's current location within the application's main structure.
**Action:** Always apply `aria-current="page"` to the active state of navigation tabs or links.
