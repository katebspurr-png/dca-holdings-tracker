## 2025-06-03 - [Micro-UX vs Global Components]
**Learning:** Modifying core UI components (like `button.tsx`) can have far-reaching effects that may violate project scope or approved design patterns, even if the intent is a micro-UX improvement.
**Action:** Focus tactile feedback (like `active:scale-95`) on specific high-traffic components (e.g., TabBar, FABs) first before suggesting global component changes.
