## 2026-05-31 - Bottom Tab Bar Navigation Accessibility & Feedback
**Learning:** For navigation tabs, using `aria-current="page"` provides essential context for screen readers, and `active:scale-95` with a synchronized `transition` offers immediate tactile feedback that enhances the mobile-first feel.
**Action:** Always verify that primary navigation elements use `aria-current` to indicate the active state and implement tactile feedback on custom button components.
