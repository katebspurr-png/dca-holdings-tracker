# Palette Agent Journal

## 2025-05-15 - Initial Journal Setup
**Learning:** Subtle tactile feedback (`active:scale-95`) in navigation elements like the BottomTabBar significantly improves perceived responsiveness and user confidence in mobile-first applications. Implementing `aria-current="page"` is critical for screen reader users to identify their location in the app's navigation.
**Action:** Always include tactile feedback and proper ARIA current states in navigation components.
