## 2025-05-14 - [Auto-focus on Modal Inputs]
**Learning:** In modal-driven applications like PositionPilot, failing to auto-focus the primary input field creates unnecessary friction (an extra click/tap) for the user.
**Action:** Always apply the `autoFocus` attribute to the first logical input field in any new or modified dialog components to ensure a "keyboard-first" or "immediate-entry" experience.
