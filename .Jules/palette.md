## 2025-05-15 - Tactile Feedback in Navigation
**Learning:** Subtle tactile feedback (`active:scale-95`) in navigation elements like the BottomTabBar significantly improves perceived responsiveness and user confidence in mobile-first applications.
**Action:** Always include `active:scale-95` and `transition` on primary navigation and action buttons.

## 2025-06-27 - Navigation Accessibility
**Learning:** Implementing `aria-current="page"` on active navigation buttons is critical for screen reader users to identify their location in the app's mobile-first navigation.
**Action:** Ensure the active state of navigation tabs is semantically communicated using `aria-current`.
